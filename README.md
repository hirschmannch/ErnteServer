# ErnteServer Updates

Öffentliche Updatequelle für den Hirschmann ErnteServer.

Dieses Repository enthält ausschließlich freigegebene Programm-Updates. Erntedaten, Mitarbeiterdaten, Zugangsdaten, `ernte.db`, `auth.env` und lokale Sicherungen gehören niemals in dieses Repository.

Der ErnteServer-Launcher liest `update/manifest.json`, prüft die SHA-256-Prüfsumme des Pakets und sichert die lokale Installation vor jedem Update.
